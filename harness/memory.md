# Memory

One-off corrections, one line each. A correction that keeps coming back belongs in CLAUDE.md, not here.

- News about a model itself (a new or domain-trained model, a lab's finding about how a model reasons or behaves, reactions to such a finding) is noise: the reader builds the harness around the model. It is signal only if the post hands them a concrete change to how they build, run or check an agent; "this might affect evals" is not enough. (R1)
- F3 does not cover a product launch (a hardware SDK, a design or art pack, an app) that only says "point your coding agent at the repo" or ships a skill for making more of that product. Ask: would this make the reader's agent better at building, running or checking any project? If it only helps make that one product, it is noise. (R2)
- Judge a post by its author's own words, not by the topic of what it quotes or attaches. If the words are hype about something a model made, the post is noise (F1, F2), even when it attaches a harness article. If they are a forecast about a market, that is noise too. If they set out how the author would have agents run, decide or check work, the post is signal. That holds even when it is a short teaser and its attached article can't be read. (R5)
