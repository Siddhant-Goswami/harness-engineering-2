TIME: minute 45 to 52. Take one failure from the room’s failure log and fix it by hand, exactly the way 101 taught. Add ONE rule to harness/CLAUDE.md and end it with the tag from the log, (F1). Commit it. Then run python3 loop.py baseline. This runs every visible week three times (nine briefs, about 20 seconds), prints a score table, and tags this commit as “baseline”. Everything after this is measured against it. On the sample, the untouched first setup scores about 0.74; with a hand fix yours will be a little higher. Read the table with the room. Point at the low-to-high column: the same setup gives different scores on different runs. Park that; we come back to it at minute 65. Narrate what you just did as four jobs: you read the output, you found the cause, you wrote the rule, you checked it worked. Each one took your attention. CLICK: “Who fixes the next twenty?” Pause here. This is the turn of the session. Their failure log already has more entries than anyone wants to fix by hand. ASK: “Which of those four jobs could a second agent do? Which would you never hand over?” Steer to: reading, finding the cause and proposing the rule can be handed over.
