TIME: minute 35 to 45. Run python3 codemode.py live. It takes about 15 seconds and prints a three-row table: one call per link, one script, and plain code as the ground truth. The numbers on the slide are from my run on week one of the sample; yours will differ a little. Read YOUR numbers, not the slide’s. Before running, ASK: “The agent has to look at 25 pages to answer this. How many times does the model need to think?” Take guesses. Way one: the agent calls the fetch tool for each link. Every page passes back through the model. Way two: the agent writes one short script. The script reads every page; only the matching ids come back. The model decided what program to write, and nothing else. CLICK: the name is code mode. Anthropic and Cloudflare both published it as a way to cut context use. Two reasons it matters today, beyond saving tokens: 1. It is “move purple to orange” from the C7 lecture, done by the agent itself. The loop and the filter become ordinary code. 2. A script that worked can be saved as a skill. That is the smallest form of a harness improving itself, and the optimizer is allowed to do it. HONEST NOTE: the token column in the terminal moves much less than the characters column, because the sample pages are tiny and the fixed system prompt dominates. On real pages of several thousand characters the gap is large. Do not quote Cloudflare’s 81% figure unless you have re-checked the source.
